# OptiSure Insurance Management

This is a full-stack insurance management application with a React frontend and a Spring Boot backend.

## How to Run

To run the application, you will need to do the following:

1.  **Start the backend:**
    *   In a terminal, navigate to the `backend` directory.
    *   Run the command `./gradlew bootRun`.
2.  **Start the frontend:**
    *   In a separate terminal, navigate to the `frontend` directory.
    *   Run the command `npm start`.

After completing these steps, the application should be accessible in your web browser at `http://localhost:3000`.
